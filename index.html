Sample OpenAPI 3.0.3 specification combining endpoints from three public/open-source APIs (Open-Meteo, REST Countries, and Open Library) with 401, 403, 404, 500, and 502 error responses on every operation.

Open-Meteo

Weather forecast endpoints (https://api.open-meteo.com/v1)

Get weather forecast by coordinates (Open-Meteo)

query Parameters
latitude
number <float>
Example: latitude=49.4216

WGS84 latitude coordinate

longitude
number <float>
Example: longitude=26.9965

WGS84 longitude coordinate

hourly
string
Example: hourly=temperature_2m,precipitation

Comma-separated hourly weather variables

timezone
string
Example: timezone=Europe/Kyiv

IANA timezone name or auto

Responses

https://api.open-meteo.com/v1/forecast

REST Countries

Country lookup endpoints (https://restcountries.com/v3.1)

Search countries by name (REST Countries)

path Parameters
name
required
string
Example: ukraine

Common or official country name

query Parameters
fields
string
Example: fields=name,capital,region

Comma-separated fields to return

Responses

https://restcountries.com/v3.1/name/{name}

Open Library

Open book catalog lookup endpoints (https://openlibrary.org)

Look up book metadata by identifiers (Open Library)

query Parameters
bibkeys
string
Example: bibkeys=ISBN:0451526538

Comma-separated book keys (e.g. ISBN:0451526538)

format
string
Default: "json"
Example: format=json

Response format (json)

jscmd
string
Example: jscmd=data

Detail level (viewapi or data)

Responses

https://openlibrary.org/api/books
